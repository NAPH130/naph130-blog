# 粒子时间时钟与局部差分更新逻辑 (Particle Clock)

简介页右上角的北京时间（UTC+8）动态粒子时钟组件。负责将当前时间点阵化为活体微游动粒子，并实现**只有发生数值变化的字符位才执行粒子重流向刷新**的局部差分更新算法。

源码文件：`src/components/ParticleClock.tsx`

---

## 1. 详细实现原理与数学模型

### 1.1 独立槽位架构与字宽权重分布
时间格式由 8 个独立字符组成：`H1` `H2` `:` `M1` `M2` `:` `S1` `S2`。
为了兼顾单字符采样的物理隔离与整行排版的自然比例，引入权重分布模型：
- 数字字符（`0~9`）权重：$1.0$
- 冒号字符（`:`）权重：$0.55$
- 总权重：$6 \times 1.0 + 2 \times 0.55 = 7.1$

根据容器宽度 $W$，每个槽位分配对应的水平中心点 $X_{\text{center}}$：
$$X_{\text{center}}(k) = \sum_{i=0}^{k-1} W_{\text{slot}}(i) + \frac{W_{\text{slot}}(k)}{2}$$

### 1.2 局部差分刷新机制（Differential Slot Update）
避免每秒全屏或全时钟粒子池大重排。维护 8 个相互隔离的粒子子池：
```ts
const slotChars: string[] = ['', '', '', '', '', '', '', ''];
const slotParticles: Particle[][] = [[], [], [], [], [], [], [], []];
```
每秒比对时间字符串的每个字符位：
1. **未变化槽位（`currentChars[i] === slotChars[i]`）**：
   - 不触发采样。
   - 不更新目标坐标。
   - 粒子严格保留在各自原有的谐波游动轨道上，维持绝对宁静。
2. **发生变化槽位（`currentChars[i] !== slotChars[i]`）**：
   - 仅对该槽位进行离屏点阵重采样。
   - 动态扩缩该槽位内部的粒子数量。
   - 该槽位内部粒子平滑流向新的数字点阵（300ms 自然过渡）。

```ts
function syncTime(force = false) {
  const currentChars = getBeijingTimeChars();
  for (let i = 0; i < 8; i++) {
    if (currentChars[i] !== slotChars[i] || force) {
      updateSlotParticles(i, currentChars[i]);
    }
  }
}
```

## 2. 踩坑点与 Bug 修复记录

### 坑 1：全局每秒重排导致小时与分钟无故跳闪
- **现象**：每过 1 秒钟，左侧的小时、中间的分钟以及冒号都会跟着产生轻微震荡与重新排列。
- **原因**：初期直接对 `"HH:MM:SS"` 整体绘制采样，导致目标点数组每秒全量洗牌，粒子被交叉分配到不同数字上。
- **修复**：解耦为 8 个独立槽位粒子池，仅秒数位或进位位触发局部差分变换，未变字符零扰动。

### 坑 2：冒号点阵采样范围侵入邻近数字
- **现象**：冒号两侧的数字边缘有时会多出杂散粒子。
- **原因**：离屏采样若进行全画布扫描，冒号与数字的采样点可能在水平重叠区互相干扰。
- **修复**：为每个槽位限制水平扫描区间 `[centerX - fontSize * 0.6, centerX + fontSize * 0.6]`，实现空间物理硬隔离。
