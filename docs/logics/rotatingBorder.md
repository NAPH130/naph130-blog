# 矩形外框与对称顺时针旋转流光算法逻辑 (Rotating Border)

围绕首页文字外接矩形边框进行 180° 对称顺时针旋转流动的双光束线条效果。

源码文件：`src/components/ParticleHero.tsx`

---

## 1. 详细实现原理与数学模型

### 1.1 边框外接矩形动态计算
在 Canvas 采样文字点阵时，提取所有文字点阵像素坐标的极值 `minX, maxX, minY, maxY`，并在四周留出对称呼吸内边距（宽屏 `padX=36px, padY=22px`）：
```ts
bounds = {
  x: minX - padX,
  y: minY - padY,
  w: Math.max(10, maxX - minX + padX * 2),
  h: Math.max(10, maxY - minY + padY * 2),
};
```
矩形总周长：$P = 2 \times (W + H)$。

### 1.2 矩形周长一维到二维坐标映射 (`getPointOnRectPerimeter`)
将一维线性弧长距离 $d \in [0, P)$ 顺时针映射为矩形四边上的 2D 坐标：
- **顶边**（$0 \le d < W$）：从左到右 $\to (x_0 + d, y_0)$
- **右边**（$W \le d < W + H$）：从上到下 $\to (x_0 + W, y_0 + d - W)$
- **底边**（$W + H \le d < 2W + H$）：从右到左 $\to (x_0 + W - (d - (W + H)), y_0 + H)$
- **左边**（$2W + H \le d < P$）：从下到上 $\to (x_0, y_0 + H - (d - (2W + H)))$

### 1.3 顺时针流光尾迹绘制 (`drawBeam`)
光束长度定为周长的 16%（`beamLength = P * 0.16`），流速为每秒 18% 周长（`speed = P * 0.18`）。
采用 30 步分段差值绘制：
- **头部**：线宽最大（3px）、不透明度最高（`alpha = 0.95`）、发光最强（`shadowBlur = 6`）。
- **尾部**：沿步长按幂函数衰减（$\text{progress} = 1 - s / \text{steps}$，$\text{alpha} = \text{progress}^{1.8}$），自然融入基准微弱线框中。
- **拐角防拉扯**：若步进两点跨越拐角距离突变，跳过单段绘制，防止在矩形四个角产生斜向对角拉扯。

### 1.4 双光束 180° 对称相位驱动
- 光束 1 头部位置：$d_1 = (\text{elapsed} \times \text{speed}) \pmod P$
- 光束 2 头部位置：$d_2 = (d_1 + P / 2) \pmod P$
严格保证两条流动线条在矩形对边呈现 180° 对称对角旋转。

## 2. 踩坑点与 Bug 修复记录

### 坑 1：矩形拐角处出现斜跨对角连线
- **现象**：光束经过矩形 4 个直角拐角时，尾迹线段会瞬间横跨矩形对角线拉出一条斜线。
- **原因**：当单段微步（$d_1 \to d_2$）恰好跨过顶点时，$d_1$ 位于顶边末端而 $d_2$ 位于右边顶端，直接用 `lineTo(pt2.x, pt2.y)` 会在二维空间画出一条切角斜线。
- **修复**：在循环中计算相邻两点的欧式几何距离。若距离异常大于步长阈值（`distDelta > (beamLength / steps) * 2.5`），判定为跨拐角段并执行 `continue` 跳过，彻底消除斜向连线。

### 坑 2：不同屏幕宽度下边框与文字重叠
- **现象**：在手机端或窗口缩小时，矩形边框紧贴甚至压入文字内部。
- **修复**：在外接矩形计算中加入响应式边距：移动端使用 `padX=24px, padY=16px`，桌面端使用 `padX=36px, padY=22px`，保证在任何分辨率下边框与文字间距适度。
